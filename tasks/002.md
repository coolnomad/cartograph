# Task 002: Scaffold the Python project and toolchain

## Objective

Create the minimal Python/uv project so Compact's default checks can run against cartograph:
a `pyproject.toml` (package `cartograph`, src layout), a locked environment, the `src/cartograph`
package, a `tests/` directory with a passing smoke test, and ruff/mypy configuration consistent
with control_plane. This task establishes the ground the schema and code tasks build on.

## Acceptance Criteria

- [ ] `uv sync` succeeds and produces a `uv.lock`
- [ ] `uv run ruff check .` exits 0
- [ ] `uv run ruff format --check .` exits 0
- [ ] `uv run mypy src/` exits 0
- [ ] `uv run pytest` exits 0 (at least one smoke test)
- [ ] `src/cartograph/__init__.py` exposes a version string
