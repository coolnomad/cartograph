# Task 003: Define node, edge, and provenance schemas

## Objective

Author canonical schemas for cartograph's graph: the `node` record, the `edge` record, and the
`provenance` stamp carried by both. Mirror Compact's schema style (front-matter + field
reference tables) and reflect the taxonomy in SPEC section 3, refined by the task 001 findings
(adopt Backstage relation names where they map cleanly; adopt OpenLineage facet-style evidence;
graded confidence keyed to evidence source).

## Acceptance Criteria

- [ ] `schemas/node.schema.md` defines all node fields, kinds, classifications, and statuses
- [ ] `schemas/edge.schema.md` defines all mechanical and conceptual edge types with required evidence
- [ ] `schemas/provenance.schema.md` defines the provenance stamp (scan run id, extractor, timestamp, evidence pointer)
- [ ] No edge is representable without evidence + provenance (enforced by the schema)
- [ ] Schemas distinguish auto-extracted fields from curated/override fields
