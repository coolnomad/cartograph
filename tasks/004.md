# Task 004: Local git-directory source adapter + classification heuristic

## Objective

Implement the v0 source adapter: scan a directory of repositories into `node` records with
detected tech, last activity, and a *proposed* classification (project / experiment / archive /
scratch) per the SPEC section 3.3 rubric. Write results as a provenance-stamped snapshot to
`extracted/`. The scanner must never write to `curated/`.

## Acceptance Criteria

- [ ] `cartograph scan <dir>` emits one node per repo with all schema-required fields populated
- [ ] Classification heuristic implements the SPEC section 3.3 scored rubric and is unit-tested
- [ ] Each node carries a provenance stamp (scan run id, extractor, timestamp)
- [ ] Snapshots are written to `extracted/` without touching `curated/`
- [ ] Running against `C:\GitHub` produces a snapshot of all top-level repos
